24Cxx 烧录器 · 数码管状态卡

前两位 = 状态码　　后两位 = 当前 ROUTER 地址（0x50 → 50）

显示 状态 含义
IdLE 空闲 上电初始，还没发 ROUTER
Id50 空闲（已选片） 流程结束回 IDLE，地址保留
SE50 已设 ROUTER 等 EDGE
Ed50 已设 EDGE 等 INT_R / INT_W
UC50 写流程进行中 U = write，C = busy
dC50 读流程进行中 d = download
为什么没有 W / R
  • 七段管画不出 W，只能用 0x3E 拼成 U 形 → 写流程统一用 U
  • R 只有 0x50 两段，像杂点 → 改用 SE / Ed / dC
为什么流程内不切换字母
  • 每包只有几毫秒，切换 ~90~180Hz，人眼会叠加：
    C ∪ o = 0x7D = 数字 6
  • 所以整个流程恒定显示 UC / dC，只在开始、结束时变
自检命令（串口助手直接敲，不影响正式协议）
  • >DISP_TEST<　YES + 全段点亮 0.2s；R-ERR = 引脚不受控
  • >I2C_TEST<　YES = 器件有 ACK；R-ERR = 没插好/地址不对/没上拉
