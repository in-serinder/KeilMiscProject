## A. 已确定

### 通道与硬件

| # | 决策 | 结论 |
|---|---|---|
| A1 | 通道结构 | **4 路功率（CH0–CH3，每路 V+I）+ 2 路温度（TH0–TH1）** |
| A2 | 电压量程 | **每通道独立分压**：CH0=12 V / CH1=24 V / CH2=64 V / CH3=100 V |
| A3 | 分压比 | **4.3 / 8.5 / 23 / 31** → 满量程 **14.19 / 28.05 / 75.9 / 102.3 V** |
| A4 | 电压分辨率 | 3.46 / 6.85 / 18.53 / 24.98 mV per count（12 bit） |
| A5 | 电流器件 | **CH0–2 = ACS712-05B（±5 A）**，**CH3 = 20 A 版（抓尖峰）**，各配运放电平搬移 |
| A6 | 电流方向 | 单极性使用，字段保留符号，负向不做精度承诺 |
| A7 | 温度器件 | **DS18B20 ×2**，**两条独立 1-Wire 总线**（PB5 / PB6），不走 ROM 搜索 |
| A8 | 冗余 ADC | **PB0/PB1 留空，暂不设计**，PCB 只留测试点 |
| A9 | MCU | STM32F103C6T6；将来容量不够换 **F103C8T6**（64K/20K 同封装） |
| A10 | 传输 | USB FS HID 64 B / 1 ms |

### 功能与软件

| # | 决策 | 结论 |
|---|---|---|
| A11 | "高频"定义 | 能捕捉到被测电源一段时间细节即可，不要求 5 kHz 逐点全传 |
| A12 | 数据模式 | RAW + BIN 双模式 |
| A13 | 使能采集 | 单指令 `ACQUIRE (0x20)`，48 B 全参数 |
| A14 | 运行中改采样 | **禁止**（`BAD_STATE`），必须 ABORT 重开 |
| A15 | ABORT | 立即停采样 → 排空 → 汇总 |
| A16 | 记录模式 | 手动 / 定时 / 触发 |
| A17 | 触发维度 | **电压 / 电流 / 功率 三选一** |
| A18 | 触发策略 | 开/关阈值分离 + 各自消抖保持时间 |
| A19 | 触发位置 | 下位机 tick 级判定 |
| A20 | 四档存储 | 设备 tier（RAW/10ms/1s/60s）+ 上位机 L0–L3 金字塔；tier0 逐点不丢 |
| A21 | tier 粒度 | 全局统一 |
| A22 | 触发前缓冲 | 不做 |
| A23 | 会话存储 | 内存窗口 + spool；手动保存才生成 `.pdl`；关闭不保存则删除 |
| A24 | 通道默认标签 | `CH0`–`CH3` / `TH0`–`TH1`，用户可自由重命名（存上位机侧） |
| A25 | 上位机 | Avalonia 11.3 / net8.0 / CommunityToolkit.Mvvm，UserControl 拆分 |
| A26 | 模拟器 | Python + Tkinter，风格参考 `51_PWMCtrol/sim` |
| A27 | 统计 | 每通道 V/I/P 全指标 + 纹波 + 尖峰 + 温度；曲线可隐藏、可缩放 |
| A28 | 工作顺序 | **先写模拟器 + 上位机，硬件等需求定完再设计** |

## B. 我按建议默认实现

| # | 议题 | 默认做法 |
|---|---|---|
| B1 | 温度数据格式 | `data_fmt=7 TEMP_C16`（℃×16，DS18B20 原生） |
| B2 | 温度上报节奏 | 独立 `temp_interval_ms`，默认 1000 ms，分辨率默认 12 bit |
| B3 | 温度时间对齐 | `sample_index` 记当时功率 tick，`t_first_ms` 插值 |
| B4 | 未采集看温度 | `READ_TEMP_ONCE (0x21)` |
| B5 | 电流负值 | 允许，UI 默认只显示正向段并标注"负向未校准" |
| B6 | 尖峰判定 | 每通道可设 V/I/P 三阈值，超限计次 + 累计时长 |
| B7 | 改参数提示 | 弹窗"将结束当前记录，是否先保存？" |
| B8 | 统计位置 | 全部上位机增量计算 |
| B9 | 温度触发 | 不支持 |
| B10 | 建链流程 | IDENTIFY → GET_CH_CONFIG ×6 → TIME_SYNC → READ_TEMP_ONCE → GET_STATUS |
