## 2. 分层职责

| 层 | 职责 | 禁止 |
|---|---|---|
| **ITransport** | 收发 64 B 报文 | 不做 CRC、分片、重试 |

### 3.2 电压前端：**4 路独立分压比**

这是本轮最大的变化——不再四路同量程，而是每路按使用场景定制：

| 通道 | 标称 | R1 | R2 | 分压比 | 满量程 | **1 LSB** | Zin | 满量程功耗 |
|---|---|---|---|---|---|---|---|---|
| CH0 | 12 V | 33 k | 10 k | 4.3 | **14.19 V** | **3.46 mV** | 43 k | 4.7 mW |
| CH1 | 24 V | 75 k | 10 k | 8.5 | **28.05 V** | **6.85 mV** | 85 k | 9.3 mW |
| CH2 | 64 V | 220 k（2×110k 串联） | 10 k | 23 | **75.9 V** | **18.53 mV** | 230 k | 25 mW |
| CH3 | 100 V | 300 k（2×150k 串联） | 10 k | 31 | **102.3 V** | **24.98 mV** | 310 k | 34 mW |

```
Vin ──[ R1 (见上表) ]──┬──[ 1k ]──┬── ADC
                      │          │
                    [ R2 10k ]  [1nF]  [BAV99 → 3.3V/GND]
                      │          │
                     GND        GND
```

**四条设计要点**

1. **R2 全部统一 10 k**，只有 R1 不同 → BOM 只多三种阻值，PCB 布局完全对称。
2. **R1 怎么拼**：CH2 用 2×110k 串联，CH3 用 2×150k 串联。0805 电阻耐压约 150 V，虽然 64 V / 100 V 单颗也勉强能扛，但串联两颗分摊电压更稳，也顺便把功耗分掉一半。
3. **滤波电容一律 1 nF，绝不能上 100 nF。**
   四路的源阻抗（R1∥R2）分别是 7.67k / 8.82k / 9.57k / 9.68k，都在 10 k 以内，1 nF 对应 τ ≈ 7.7–9.7 µs、带宽 16–20 kHz，刚好覆盖 2.5 kHz 的采集上限。
   换 100 nF 则 τ ≈ 1 ms、带宽 160 Hz —— **纹波会被彻底滤掉，这个项目的核心用途就没了**。
4. **通道量程不同 = 不能插错。** 把 100 V 接到 CH0（4.3:1）上，分压点就是 23 V，1 kΩ 串联上要掉 0.39 W。丝印必须把每路量程写清楚，钳位二极管只能救"短时"误接，救不了"接反了跑一小时"。

**分辨率对照（这才是分档的意义）**

| 通道 | 满量程 | 1 LSB | 测 12 V 时用到量程 |
|---|---|---|---|
| CH0 | 14.19 V | **3.46 mV** | 85%（几乎满量程，纹波看得清） |
| CH1 | 28.05 V | 6.85 mV | 43% |
| CH2 | 75.9 V | 18.53 mV | 16% |
| CH3 | 102.3 V | 24.98 mV | 12% |

同一块板子上，CH0 看 12 V 电源纹波的分辨率是 CH3 的 **7 倍**。这就是按用途分档的价值——之前"四路都 100 V"的方案，测 12 V 时浪费了 3 个 bit。

**协议对应**：每路的满量程与换算系数都是**每通道独立**的，通过 `GET_CH_CONFIG` 读回（见 02 文档 5.6）。上位机连上设备后必须逐通道读一次，不能假设四路一样。

### 3.3 电流前端：ACS712 + 运放（必须有运放）

**为什么必须要运放**：ACS712 零点固定在 `Vcc/2 = 2.5 V`，5 A 版灵敏度 185 mV/A，±5 A 时输出 2.5 ± 0.925 = **1.575 ~ 3.425 V**。上限 3.425 V 已经超过 3.3 V 参考电压，**直接用 ADC 测，到 4.3 A 就削顶了**。

20 A 版更严重：±20 A 输出 0.5 ~ 4.5 V，直接测只能到 8 A。

运放的职责就是**把 2.5 V 中点搬到 1.65 V，并把摆幅缩放到 0 ~ 3.3 V**：

```
Vout = (V_acs - 2.5 V) × G + 1.65 V
```

| 参数 | CH0–CH2（05B） | CH3（20A） |
|---|---|---|
| ACS 灵敏度 | 185 mV/A | 100 mV/A |
| 满量程 | ±5 A | ±20 A |
| ACS 输出摆幅 | ±0.925 V | ±2.0 V |
| 运放增益 G | 1.65 / 0.925 = **1.784** | 1.65 / 2.0 = **0.825** |
| 运放输出 | 0 ~ 3.3 V（满摆） | 0 ~ 3.3 V（满摆） |
| 等效灵敏度 | 330.1 mV/A | 82.5 mV/A |
| counts/A | 409.7 | 102.4 |
| **分辨率** | **2.44 mA** | **9.77 mA** |

**电路要点**

1. 单电源 3.3 V、轨到轨运放（MCP6002 / TLV9062 / OPA2340 均可）。
2. 用**差分放大器**结构（4 个电阻），电阻取 0.1% 精度，否则共模误差会直接变成零点漂移。
3. **2.5 V 基准必须由 ACS712 的同一路 5 V 分压得到**（加缓冲），不能另找一路 3.3 V 分压——ACS712 的零点跟着自己的 Vcc 走，两路不一致就会随温度漂。
4. 运放输出串 100 Ω + 1 nF 到 ADC，同上，别用大电容。
5. 20 A 版分辨率只有 9.77 mA（比 05B 差 4 倍），这是选它的代价——它本来就是用来抓**尖峰**的，不是用来测小电流的。

### 3.4 温度前端：DS18B20

| 参数 | 值 |
|---|---|
| 接口 | 1-Wire，单总线，需 4.7 kΩ 上拉 |
| 分辨率 | 9–12 bit 可配（0.5 / 0.25 / 0.125 / 0.0625 ℃） |
| 转换时间 | 93.75 / 187.5 / 375 / **750 ms** |
| 精度 | ±0.5 ℃（-10 ~ +85 ℃） |
| 数据格式 | 16 bit 有符号，`值 / 16 = ℃` |

**三个必须处理的坑**

1. **750 ms 转换时间**：12 bit 下温度最快只能 1.3 次/秒。所以温度上报间隔必须 ≥800 ms。想快就降到 9/10 bit。
2. **不能阻塞主循环**：发完 `Convert T` 命令后要立刻返回，用状态机在 750 ms 后回来读，不能在原地等。
3. **85 ℃ 是上电默认值**，不是真实温度。读到 `0x0550` 必须判为"未完成转换"，不能上报。这个坑 90% 的初学者都会踩。

### 3.5 资源天花板

| 资源 | 数量 | 影响 |
|---|---|---|
| Flash | 32 KB | USB HID 栈 ~10–12 KB + 1-Wire ~2 KB，逻辑剩 ~16 KB |
| SRAM | **10 KB** | USB ~1.5 KB + 块缓冲 ≤3 KB + 栈 |
| ADC | 1 个，12 bit，已用 8/10 通道 | 剩 2 路冗余 |
| USB | 仅 FS，64 B/ms | 上限 64 kB/s |
| FPU | 无 | 全整数 / 定点 |

### 3.6 ADC 时序

- ADCCLK 14 MHz，采样 13.5 + 转换 12.5 = 26 周期 ≈ **1.86 µs/通道**
- 8 通道全扫 ≈ 14.9 µs → 扫描上限约 **67 kHz**
- 本项目的实际上限由 USB 决定（2.5 kHz），ADC 完全不是瓶颈

扫描顺序固定 `V0,I0,V1,I1,V2,I2,V3,I3`，同通道 V/I 相邻，偏斜 1.86 µs。

| 场景 | 偏斜影响 |
|---|---|
| 平均功率 | 可忽略 |
| 50/60 Hz | 相位误差 < 0.05° |
| 100 kHz 纹波 | 1.86 µs ≈ 周期 18%，相位不可信 |

### 3.7 冗余 ADC（PB0 / PB1）

**本轮不设计，留空。** 引脚在 PCB 上做成两个过孔/测试点即可，将来想加东西再飞线。

理由：现在分通道量程已经把"分辨率不够"这个主要矛盾解决了，不需要靠冗余 ADC 做档位检测；5 V 电源监测可以等整机联调时再看要不要。

将来若要加，优先级：`5 V 电源监测`（ACS712 零点漂移预警）> `外部 NTC` > 其它。

## 5. 关键设计决策

### KD-1：上位机主控，运行中锁定参数

`ACQUIRE` 一次下发全部参数；运行中改任何采集/通道/校准参数 → `BAD_STATE`。
UI 上不是提示，是**把控件置灰禁用**。改参数必须先 ABORT，明确提示"将结束本次记录"。

好处：记录文件里配置唯一，回放与统计不用处理配置分段；固件状态机简单（10 KB RAM 下这点很重要）。

### KD-2：双上报模式（RAW / BIN）

- RAW：4ch 1 kHz 占 33% 带宽，2 kHz 占 67%，2.5 kHz 是上限
- BIN：4ch × 10 ms 桶 = 6.4 kB/s

### KD-3：四层金字塔存储 ★

| 层 | 桶宽 | 保留 | 体积（4ch） |
|---|---|---|---|
| L0 逐点无损 | — | 60 s | 0.96 MB @1 kHz |
| L1 峰值保持 | 10 ms | 1 h | 23 MB |
| L2 秒级 | 1 s | 24 h | 5.5 MB |
| L3 分钟级 | 60 s | 永久 | 0.09 MB/天 |

24 h ≈ **30 MB**（全分辨率是 1.38 GB，压 45 倍）。

每层存 `min/max/avg/rms/count`，内部另存 `sum/sumsq`（i64）。

合并：
```
count' = n1+n2 ; min' = min ; max' = max
sum' = sum1+sum2 ; sumsq' = sumsq1+sumsq2
avg' = sum'/count' ; rms' = sqrt(sumsq'/count')
```

只留 avg 会漂移且 rms 无法重算——**这是唯一容易写错的地方**。

回放按缩放级别选层：>1 h 用 L2，>1 min 用 L1，否则 L0。

### KD-4：会话在内存，手动保存（spool，已确认）

```
开始 → %TEMP%\PDL\{guid}.pdl.part，内存只留最近窗口
保存 → 写 Index+Footer → 改名 .pdl
丢弃 → 删临时文件
崩溃 → 残留文件，下次启动提示可恢复
```

UI 语义："没点保存就没有正式文件"，标题栏显示"未保存会话 · 128 MB"。

### KD-5：触发判定在下位机，V/I/P 三源

| source | 阈值单位 | 计算 |
|---|---|---|
| 0 电压 | mV | `(v_raw - v_off) × num/den` |
| 1 电流 | mA | `(i_raw - i_off) × num/den` |
| 2 功率 | mW | `V_mV × I_mA / 1000`（i64 中间量） |

```
ARMED：越过 start_val → 启动 hold 计数（累加 tick）
        期间回落 → 清零（消抖）
        持续 ≥ start_hold_ms → 触发 → RUNNING
RUNNING：越过 stop_val 持续 ≥ stop_hold_ms → 收尾（+post_trigger_ms）
```

消抖用 tick 累加，绝不用 `delay_ms`。`trig_flags.bit2` 支持自动重武装。

### KD-6：协议单一真源

`protocol/pdl_protocol.yaml` → 生成 C# / Python / C 三端常量与 DTO。M1 就做。

### KD-7：时间基准

`sample_index` 为权威排序键，`t_first_ms` 辅助；TIME_SYNC 算 offset（RTT/2），长跑每 30 s 重同步；温度块用 `t_first_ms` 插值到功率轴。

### KD-8：统计指标集

**功率通道**

| 类别 | 指标 |
|---|---|
| 电压 | Vavg Vmin Vmax Vpp Vrms Vrms_ac 纹波率 |
| 电流 | Iavg Imin Imax Ipp |
| 功率 | Pavg Pmax Pmin 峰值因子 |
| 事件 | 尖峰次数 超限时长 饱和次数 |
| 派生 | 负载调整率 (Vmax-Vmin)/Vavg，稳定度 std(V)/Vavg |

**温度通道**：Tavg Tmin Tmax 上升速率（℃/min）

**会话级**：时长 总tick 总块 丢块 丢点率 平均帧率 触发次数 体积

全部增量计算（O(1) 每块）：RAW 块累加 sum/sumsq/min/max；BIN 块用桶的 min/max 与 n 加权合并。

**尖峰**：每通道可设 V/I/P 三个阈值，超过计数并累计时长。这是把"稳定性"量化成一个数字的关键。

## 7. 下位机职责

| 能力 | 要求 |
|---|---|
| 功率通道 | 4 路 V/I，顺序扫描，V/I 相邻 |
| 温度通道 | 2 路 DS18B20，独立状态机，不阻塞 |
| 采样率 | 1 Hz – 20 kHz（实际上报受 USB 限制） |
| 缓冲 | ≥100 ms tick（1 kHz 下 ≥100 tick ≈ 2 KB） |

| 触发 | tick 级判定 + 计数消抖，V/I/P |
| 看门狗 | 断连后回到可识别状态 |

模拟器 GUI 要能**手动制造触发场景**（把 CH0 从 10 V 拉到 13 V 并保持 50 ms），否则触发逻辑没法验。

真实性开关（默认全开）：`--hid-pacing`（64 B/1 ms 限速）、`--ram 10240`（复现溢出）、`--adc-bits 12`、`--jitter-us 20`。

## 12. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| **通道量程不同，插错会烧** | 100 V 接 CH0 → 分压点 23 V | 丝印标清 + 1k 串联 + BAV99；验收时逐路打标 |
| 分压滤波电容选太大 | 纹波被滤掉 | 四路统一 1 nF |
| ACS712 输出超 3.3 V | 4.3 A 就削顶 | 运放电平搬移（必须） |
| 20 A 档分辨率 9.77 mA | 小电流测不准 | 它只用于抓尖峰，UI 标注量程 |
| DS18B20 750 ms | 温度响应慢 | 12 bit + 1 s；要快用 9/10 bit |
| DS18B20 读 85 ℃ | 误判高温 | 识别 `0x0550` 判为未完成 |
| 10 KB RAM | 缓冲仅 ~150 tick | 缓冲 ≤3 KB + BIN 模式 |
| 运行中禁改参数 | 用户想调要重开 | UI 明确提示并可"另存当前段" |
| 内存会话 | 长跑占磁盘 | spool + 体积显示 |
