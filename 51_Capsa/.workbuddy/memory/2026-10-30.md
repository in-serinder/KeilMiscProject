# 2026-10-30

## Capsa 上位机（Avalonia 11.3.12 / net8.0）前端主界面搭建

- 目录：`Capsa/` 为 MVVM 工程，参考 `51_24Cxx_Copier` 的 HexView 用法与控件风格。
- 已完成：顶部串口栏（下拉框默认「未选择串口」+ 刷新/连接）、左侧属性面板（noting.svg 转成的矢量插画空状态 / 设备名·UID·型号·类型·容量·使用率·时间·健康分）、右侧 8 张 0x50-0x57 单元卡片（整卡为蓝色进度条，ERR/WARN/HEALTH）、写入/读取标签页、HEX/纯文本/双显三编辑器（共享 EditorDocument，双向同步）、底部 GitHub + 版本。
- 架构分层：`Models/`（含 EditorDocument、HealthScale、MemoryLineReader）、`Services/`（ISerialPortService / IDeviceService / ITransferService / IFilePickerService + Mock 实现，`AppServices` 为替换点）、`ViewModels/{Shell,Panels,Editors}`、`Views/{Shell,Panels,Editors,Illustrations}`、`Styles/Tokens.axaml`（主题令牌）+ `Styles/Controls.axaml`（扁平控件样式）。
- 关键实现细节：
  - HexView 控件需命令式设置 HexFormatter / LineReader；轮询 `GetEdits()` 回写缓冲区实现 HEX→文本同步，文本侧 300ms 防抖后 `CommitText()` 并重建 HEX 控件清除编辑日志。
  - 卡片进度用 `ScaleTransform.ScaleX` 绑定 `OccupancyRatio`（Grid.ColumnDefinitions 无法用属性绑定）。
  - Fluent ProgressBar 默认 MinWidth=200，必须置 0 否则溢出。
  - Avalonia 不支持 SVG 渲染且本机 NuGet restore 损坏（缺 ProgramData 环境变量导致 `_GetRestoreSettings` 抛 path1 null），故 noting.svg 已用脚本转成矢量 Path XAML（`Views/Illustrations/EmptyCardIllustration.axaml`），构建需用 `dotnet build --no-restore`。
  - 隐藏开关：环境变量 `CAPSA_SHOT=<目录>` 会依次连接、导入示例、切换模式并截图（`Diagnostics/ScreenshotHarness.cs`）。
